# Disrob

Discord bot for Unicode text styles.

Commands:
- /text Smile = Hello
- /styles

The bot deletes the command message and sends the converted text.

Render:
1. Create a Render Web Service from this repository.
2. Set DISCORD_TOKEN to your Discord bot token.
3. Use the included render.yaml or the commands from it.

The /health endpoint is provided for uptime monitoring.

Discord permissions:
- View Channel
- Send Messages
- Manage Messages

Enable Message Content Intent in the Discord Developer Portal.
